분석 결과 개요

최종 업데이트: 2026-03-31

25개 분석 트랙 결과 요약

본 연구는 K-하이테크 플랫폼 4개년 데이터(282건, 166변수)를 대상으로 1차 탐색/준실험(13개) + 2차 인과/구조(12개) = 총 25개 분석 트랙을 수행하였다. 탐색적 분석부터 인과추론, 구조 모형까지 다층적 접근을 통해 중소기업 디지털 전환 교육의 효과를 다각적으로 검증하였다.

1차 분석 트랙별 결과 요약 (T0~T9, 탐색/준실험)

트랙 분석명 핵심 결과 상태
T0 탐색적 분석 DT인식↔︎교육효과 상관 약함(r=-.13~+.08), 만족도 천장효과, 조직환경이 최적 DV 완료
T1 회귀/요인 DT인식 3항목 단일요인(alpha=.861), 스마트시스템 7영역 단일요인(alpha=.926), MES실무 Q3최고(+1.93) 완료
T2 LPA 3-class 최적(Entropy=0.846): 미인식형/인식-미실행형/적극전환형 완료
T3 QCA 8개 충분 경로 도출, 등결과성(equifinality) 확인 완료
T4 종단분석 교육훈련수준 +0.77(d=0.60), 4가지 궤적 유형 도출 완료
T5 STM 7개 토픽(k=7), 11개 공변량 효과, LPA 프로파일별 토픽 차별화 확인 완료
T6 네트워크 밀도 0.719, 빅데이터 허브, 3개 커뮤니티, MCA 2차원 완료
T7 IPA 교육필요성-수준 갭 1.84점, 설비자동화 지속 최저 완료
T8-1 패널회귀 Pooled OLS(cluster SE), RE, FE 비교, Hausman 검정 완료
T8-2-1 PSM(DT교육경험) DT교육경험의 인과적 효과 추정 완료
T8-2-2 PSM(SF도입) SF도입의 인과적 효과 추정 완료
T8-2-3 PSM(복수참여) 복수참여의 인과적 효과 추정 완료

2차 분석 트랙별 결과 요약 (T10~T21, 인과/구조)

1차 분석에서 탐색적으로 발견한 패턴을 인과적으로 검증하고, 구조적 메커니즘을 규명하는 12개 심화 모형이다.

트랙 모델 방법 이론 핵심 결과 상태
T10 M8 Staggered DID 경험학습 TWFE null, 용량-반응(교육훈련 B=0.636, p<.001) 유의 완료
T11 M1 위계적 회귀 교육전이 DT인식→Q3_차이 B=-0.017, p=.879 (null 재확인) 완료
T12 M2 매개분석 Holton HRD ACME=0.017, p=.422 (매개 경로 차단) 완료
T13 M12 순차매개 인적자본 a=0.716(p<.001), 전체경로 차단 완료
T14 M5 규모조절회귀 LoS 대기업 역설 (B=-0.282), J-N 전환점 없음 완료
T15 M4 2x2 ANOVA 보완성 SF x 복수참여 역시너지 F=8.285, p=.004 완료
T16 M6 조절매개 흡수역량 AC 역전, DT부서 보유 시 경로a 소멸 완료
T17 M7 TOE 경로분석 TOE TOE 내부 유의(beta=.32~.49), DV 경로 전멸 완료
T18 M3 순서 로지스틱 성숙도 OR=1.411, p=.016 (단계적 전환) 완료
T19 M9 LPA 4-class 인원 중심 4프로파일, 보상효과 발견 완료
T20 M10 fsQCA+DID 등결과성 3경로, ~DT_AWARE 포함 (인과적 등결과성) 완료
T21 M11 CLPM 동적역량 E→T beta=.488 최강 (인프라→인식 역방향) 완료

분석 간 연계 구조

[1차 탐색/준실험: T0~T9]
T0 탐색적 분석
  ├── T1 회귀/요인 (변수 구조 확인 → 모형 구축)
  ├── T7 IPA (갭 구조 탐색)
  ├── T2 LPA (프로파일 도출)
  │    └── T5 STM (프로파일별 토픽 차별화)
  │    └── T3 QCA (프로파일을 조건변수로 투입)
  ├── T4 종단분석 (복수참여 기업 변화)
  ├── T6 네트워크 (기술수요 패턴)
  └── T8 인과추론 (패널회귀 + PSM 3종)

        │ 1차 발견 → 2차 검증
        ▼

[2차 인과/구조: T10~T21]
T10 DID (1차 T4/T8의 인과적 확인)
  ├── T11 기본회귀 (T1 null 재확인)
  ├── T12 매개 (T1 조직환경 매개 검증)
  ├── T13 순차매개 (인적자본 경로)
  ├── T14 규모조절 (T8 기업규모 효과 심화)
  ├── T15 상호작용 (T8_2_2 SF 역시너지)
  ├── T16 조절매개 (흡수역량 역전)
  ├── T17 TOE 경로 (T5 TOE 구조 검증)
  ├── T18 성숙도 (비선형 전환)
  ├── T19 LPA 4-class (T2 확장)
  ├── T20 QCA+DID (T3 인과적 확장)
  └── T21 CLPM (인과 방향 검증)

5대 관통 패턴

1-2차 분석(25개 트랙)을 관통하는 5가지 핵심 패턴:

패턴 1차 증거 2차 확인
인식-성과 단절 T1 R2=.005, T2 프로파일 무차이 M1 B=-.017(null), M2 매개 차단, M7 DV 전멸
더 많이 가진 역효과 T2 고준비 Q3 무차이, T8_2_2 SF ATT=0 M5 대기업 역설, M4 역시너지 p=.004, M6 AC 포화
TOE 내부만 강함 T5 기술장벽 53% M7 beta=.32~.49(유의), DV 전멸
용량-반응 분리 T4 인식 d=.55 vs Q3 n.s. M8 DID 교육훈련 p<.001 vs Q3 n.s.
등결과성 T3 필요조건 없음, 다경로 M10 DID 조건 추가 후 3경로, ~DT_AWARE

방법론적 삼각검증

본 연구는 다음 4가지 차원에서 삼각검증(triangulation)을 달성하였다:

  1. 방법론 삼각검증: 변수중심(T0,T1,T11~T18) + 사람중심(T2,T19 LPA) + 조건조합(T3,T20 QCA) + 텍스트(T5 STM) + 인과추론(T10 DID, T21 CLPM)
  2. 데이터 삼각검증: 횡단(T0~T3) + 종단(T4,T21) + 인과추론(T8 PSM, T10 DID)
  3. 분석수준 삼각검증: 개인수준(설문) + 기업수준(패널) + 텍스트수준(비정형)
  4. 이론 삼각검증: 16개 이론 적용 (TOE, 교육전이, 흡수역량, 등결과성, 경험학습, 동적역량 등)
