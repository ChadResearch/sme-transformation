분석 버전 로그

Version 1.0: 전체 렌더링 및 종합 (2026-03-28)

  • 16개 QMD 보고서 전체 렌더링 (4포맷 x 16 = 64개 파일)
  • 종합해석 및 판단 문서 작성
  • 1차 임시분석 보고서 (apaquarto) 작성
  • 1차 임시분석 보고서 해설본 (narrative) 작성
  • 7대 핵심 발견 도출
  • 3편 논문 추천 전략 수립
  • 삼각검증 체계 확립

Version 0.4: T7 IPA + T8 인과추론 (2026-03-28)

  • T7: IPA 갭분석 (교육필요성-수준 갭 1.84점)
  • T7: 스마트시스템 7영역 연도별 레이더차트
  • T8-1: 패널회귀 (Pooled OLS, RE, FE, Hausman 검정)
  • T8-2-1: PSM DT교육경험 (선택편향 통제 후 효과 추정)
  • T8-2-2: PSM SF도입 (선택편향 통제 후 효과 추정)
  • T8-2-3: PSM 복수참여 (선택편향 통제 후 효과 추정)

Version 0.3: T4 종단 + T5 STM + T6 네트워크 (2026-03-28)

  • T4: 종단분석 (대응표본 t-test, 교육훈련수준 +0.77, d=0.60)
  • T4: 변화 궤적 유형화 (지속성장형/초기도약형/정체형/하향형)
  • T4: Spaghetti Plot, Dumbbell Plot 시각화
  • T5: STM 토픽모델링 (k=7, 11개 공변량)
  • T5: LPA 프로파일별 토픽 차별화 분석
  • T5: 복수참여 기업 텍스트 변화 추적
  • T5: 다중 텍스트 컬럼별 독립 분석 (DT애로사항, TO_BE, 성과상세, AS_IS)
  • T6: 네트워크 분석 (밀도 0.719, 허브: 빅데이터)
  • T6: 커뮤니티 탐지 (Louvain, 3개 군집)
  • T6: MCA 다중대응분석, 연관규칙 (Apriori)

Version 0.2: T1 회귀 + T2 LPA + T3 QCA (2026-03-28)

  • T1: CFA (현업적용도 4구인), 위계적 회귀
  • T1: 과정유형별 비교 (MES실무 Q3차이 최고 +1.93)
  • T2: LPA 1~5 class 비교 → 3-class 최적 (Entropy=0.846)
  • T2: 3개 프로파일 명명 (DT미인식형/인식-미실행형/적극전환형)
  • T2: BCH-proxy ANOVA, mclust 교차검증
  • T3: fsQCA 캘리브레이션 (fuzzy 3 + crisp 2)
  • T3: 8개 충분 경로 도출 (등결과성 확인)
  • T3: 강건성 검정 (consistency 기준 변동)

Version 0.1: T0 탐색적 분석 (2026-03-28)
